I

Tujuan Pembelajaran

  • Mengonfigurasi parameter IP & DNS Client (Windows 10/11) agar terhubung tepat ke Domain Controller (SRV-DC01).
  • Melakukan proses *Join Domain* workstation client ke domain labnasional.local sesuai prosedur.
  • Mengonfigurasi Group Policy Object (GPO) untuk pembatasan antarmuka (*UI restriction*) dan kebijakan keamanan terpusat.
  • Mengonfigurasi Shared Folder dengan kombinasi *NTFS Permissions* dan *Share Permissions* pada Windows Server.
  • Melakukan *Drive Mapping* otomatis (Network Drive Z:) melalui GPO Preferences untuk pengguna domain.

III

Prosedur Praktik (Langkah Kerja)

Progres langkah praktik 0 dari 5 selesai

1. Pengaturan Jaringan & Uji Konektivitas Client (10 Menit)

Set IP static 192.168.10.10 dan DNS 192.168.10.1. Uji koneksi dengan perintah ping 192.168.10.1 & nslookup labnasional.local.

2. Proses Join Domain dari Mesin Client (15 Menit)

Buka sysdm.cpl, ubah nama komputer menjadi CLI-LAB01, gabungkan ke domain labnasional.local menggunakan kredensial LABNASIONAL\Administrator.

3. Konfigurasi Shared Folder & Permissions di Server (20 Menit)

Buat folder C:\Data_Siswa, berikan *Share & NTFS Permissions* untuk grup G_Teknisi dengan hak akses Full Control / Modify.

4. Konfigurasi Group Policy Object (GPO) (25 Menit)

Buat GPO GPO_Siswa_Policy di OU TKJ_Users untuk memblokir Control Panel dan melakukan *Mapped Drive Z:* otomatis.

5. Login User Domain & Pengujian Client (20 Menit)

Login ke client dengan akun siswa01, jalankan gpupdate /force, lalu verifikasi pembatasan UI & Drive Z:.

Troubleshooting Common Issues

1. Error DC labnasional.local could not be contacted

Solusi: Pastikan DNS Client sudah mengarah ke 192.168.10.1 atau tambahkan rule firewall ICMP/AD.

2. Error "Access is Denied" saat akses Shared Folder

Solusi: Periksa *Share* & *NTFS Permission* folder pastikan grup G_Teknisi sudah dimasukkan.
